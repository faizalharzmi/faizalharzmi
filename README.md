## Engineering Principles

- Prefer maintainable boundaries over accidental complexity.
- Make reliability and failure handling part of the design.
- Use secure defaults and keep secrets out of source control.
- Explain trade-offs, assumptions, and operational consequences.
- Automate repeatable checks with tests and CI.
- Modernise incrementally while protecting working behaviour.
